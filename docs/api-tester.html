Audit Keamanan API

Hasil analisis statis kode sumber — app/Http/Middleware/ApiKeyAuth.php, app/Http/Controllers/Api/AduanController.php, routes/api.php

🔴 HIGH — API Key Hardcoded

API key sk_live_wbs_superapps_2026 ter-hardcode langsung di source code ApiKeyAuth.php:14 dan juga terekspos di API_DOCUMENTATION.md. Siapapun yang membaca kode atau dokumentasi bisa menggunakan key ini.

  • Pindahkan ke .env: SUPERAPPS_API_KEY=...
  • Hapus fallback hardcoded — hanya gunakan config()
  • Rotasi key sekarang jika sudah pernah di-commit ke git

🔴 HIGH — Timing Attack pada Validasi Key

in_array($apiKey, $validKeys) rentan timing attack — penyerang bisa mengukur perbedaan waktu respons untuk menebak karakter API key satu per satu.

  • Ganti dengan hash_equals():
    hash_equals($validKey, $apiKey)

🟠 MEDIUM — Tidak Ada Rate Limiting di API

Tidak ada throttle middleware pada route API. Endpoint POST /api/aduans/status bisa di-brute force untuk menebak tracking_password. Endpoint POST /api/aduans bisa di-spam untuk flooding database.

  • Tambahkan di routes/api.php: ->middleware('throttle:60,1')
  • Untuk /status: batasi lebih ketat, misal throttle:20,1

🟠 MEDIUM — Error Detail Bocor ke Client

Saat APP_DEBUG=true, response 500 menyertakan $e->getMessage() yang bisa mengekspos nama tabel, path file, atau query database.

'error' => config('app.debug') ? $e->getMessage() : null

Pastikan APP_DEBUG=false di production, dan pertimbangkan menghapus conditional ini sepenuhnya.

🟠 MEDIUM — Endpoint Publik Tanpa Rate Limit

GET /api/jenis-aduans tidak memerlukan auth dan tidak ada throttle. Bisa dieksploitasi untuk scraping atau DDoS kecil-kecilan karena melakukan query DB setiap request.

  • Tambahkan throttle:120,1
  • Respons sudah dari cache (JenisAduan::active()) — bagus, tapi rate limit tetap perlu

🟡 LOW — MIME Type Bocor di Error Message

FileValidationService.php:79 menyertakan MIME type aktual di pesan error:

'Tipe file tidak diizinkan. MIME type: ' . $realMimeType

Memberi informasi kepada penyerang tentang tipe file apa yang diblokir dan bagaimana cara melewatinya.

🟡 LOW — Tidak Ada Log Gagal Autentikasi

Request dengan API key yang salah langsung ditolak tanpa dicatat ke log. Aktivitas mencurigakan (percobaan brute force key) tidak terdeteksi.

  • Tambahkan Log::warning() saat key tidak valid beserta IP address-nya

✅ BAIK — Yang Sudah Aman

  • Semua query pakai Eloquent ORM — tidak ada SQL injection
  • Validasi input lengkap dengan $request->validate()
  • File divalidasi berdasarkan konten MIME (bukan ekstensi)
  • Transaksi DB dengan rollback saat error
  • File upload disimpan di public disk dengan nama unik
  • tracking_password di-hash dengan bcrypt
